## Modelos de Dados

- Descrição formal dos dados que estão no banco de dados.
- Descreve os conceitos dos bancos de dados.
- Abstrai a realidade.

## Modelo Conceitual:

- Descreve os dados que vão se relacionar no banco de dados;
- Utiliza da esquematização MER (Modelo Entidade e Relacionamento);
- Qualquer SGBD funciona com o modelo;
- Define as relações, entidades e toda a concepção inicial do banco de dados.
## Modelo Lógico:

- Vem do modelo conceitual;
- Estrutura o banco de dados (campos do banco);
- Utiliza do MR (Modelo Relacional);
- Todas as tabelas são idealizadas, para serem feitas no modelo físico.
## Modelo Físico:

- Ferramenta escolhida como SGBD;
- Utiliza de alguma linguagem de dados;
- Só funciona no seu SGBD específico;
- SQL e noSQL são possibilidades.
