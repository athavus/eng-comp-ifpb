
## Introdução

-> Os pinos dos microcontroladores são a interface para as interações com o mundo exterior.

-> Cada pino, possui um circuito responsável, que pode ser configurado para diferentes tipos de funções, no caso, entradas, saídas e circuitos analógicos/especiais.

-> GPIOs, como são chamados, são os pinos de propósito geral (General Purpose Input/Output).

## Tipos de entrada:

-> Entrada digital: Detecta quando um pino está no nível lógico alto ou baixo.
-> Saída digital: Envia um sinal de nível lógico alto ou baixo para um pino.
-> Função analógica: Executa conversões DA ou AD.
-> Funções especiais: saídas de sinal PWM, driver para displays LCD, entrada de captura de eventos, interrupções externas, interfaces de comunicação USART, SPI, I2C, USB, Ethernet, etc, são as AFs (Alternate Functions).

## Número de pinos

-> STM32F407 possui 80 pinos de I/O que podem ser configurados da forma necessária.
	- São agrupados em circuitos internos conhecidos como "portas", que possuem os mesmos registradores de controle.
	- no STM32F407 são 4 portas GPIO, GPIOA, GPIOB, GPIOC, GPIOD, GPIOE, cada uma com 16 pinos de I/O, nomeados de Px0 (menos significativo) a Px15 (mais significativo), onde x é a letra da porta em questão.
	- Um pino não pode ser usado para mais de uma função, em runtime você até pode alterar a função de um pino, mas o microcontrolador precisa estar configurado para isso.

## Faixa de Tensão

-> Apesar do STM32F407 ser alimentado com uma tensão de 3,3V, quando os pinos estão operando como entradas digitais, também é possível utilizar a faixa de tensão de 0V a 5V, mas isso não ocorre quando se está operando com entradas analógicas (máximo de 3.3V).

-> Pino de alta impedância (High-Z): É um pino que não tem influência sobre o circuito elétrico ao qual está conectado.

-> Pino Flutuante: É um pino que tem que estar desconectado e não tiver acionamento pelo circuito do microcontrolador. Seu estado é indefinido e imprevisível.

-> Resistores de pull-up e pull-down: São resistores para forçar um nível lógico específico (0 ou 1), onde o resistor de pull-up é conectado entre a fonte de alimentação e o pino, para permitir que existe o estado lógico 1 e o resistor de pull-down é conectado entre o pino e o terra para conseguir enviar o estado lógico 0.
