## O que é um SGBD?

Sistema Gerenciador de Banco de Dados.

- É um sistema que dispões regras para gerenciar os dados, regras essas que envolvem:
	- Acesso;
	- Manipulação;
	- Organização;
	- Manutenção;

- Possuindo características e usos semelhantes:
	- Concorrência;
	- Abstração;
	- Padrões Reforçados;
	- Segurança;
	- Suporte a Múltiplas Visões de Dados;
	- Otimização;
	- Relacionamentos;
	- Criação de Aplicações

- Alguns exemplos de SGBD são:
	- MongoDB
	- MySQL
	- MariaDB
	- PostGreeSQL
		- SQLite
