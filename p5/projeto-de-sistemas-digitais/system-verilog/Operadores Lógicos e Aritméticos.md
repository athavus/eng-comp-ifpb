-> Em system verilog os operadores lógicos funcionam muito parecido com as linguagens convencionais, onde temos:

&& = AND lógico
! = NOT lógico
|| = OR lógico

& = AND bit-a-bit
~ = NOT bit-a-bit
| = OR bit-a-bit

^ = XOR bit-a-bit

---

<< = Deslocamento de bits a esquerda
\>> = Deslocamento de bits a direita

==  = Comparação de igualdade
!= = Comparação de diferença

< = Menor que
<= = Menor ou igual
\> = Maior que 
\>= = Maior ou igual  

---

\+ = Adição
\- = Subtração
/ = Divisão
\* = Multiplicação
% = Módulo
