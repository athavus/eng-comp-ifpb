Uma **Matriz de Adjacência** é uma forma de representar grafos em uma matriz quadrada `n x n`, onde `n` é o número de vértices.

- Cada posição `M[i][j]` indica se existe uma aresta entre os vértices `i` e `j`.  
- Para **grafos não direcionados**, a matriz é **simétrica**.  
- Para **grafos direcionados**, a matriz pode ser assimétrica.  
- Em grafos ponderados, `M[i][j]` pode conter o **peso da aresta**.  

**Exemplo:**

Seja `N = {x, y, z, w}` e `A = {a1, a2, a3}`:

- g(a1) = x–y  
- g(a2) = y–z  
- g(a3) = x–w  

A matriz de adjacência é:

|     | x   | y   | z   | w   |
| --- | --- | --- | --- | --- |
| x   | 0   | 1   | 0   | 1   |
| y   | 1   | 0   | 1   | 0   |
| z   | 0   | 1   | 0   | 0   |
| w   | 1   | 0   | 0   | 0   |

---

### Vantagens

- Consulta rápida `O(1)` para saber se dois vértices são adjacentes.

### Desvantagens

- Consome muito espaço `O(n²)`, mesmo em grafos esparsos.
