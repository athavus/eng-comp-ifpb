

## Multiconjuntos

-> Possui todas as características de um conjunto normal, mas possibilitando a repetição de elementos dentro de seu escopo.

---
## Cardinalidade

-> Conjuntos possuem três tipos de classificações em relação a sua quantidade de elementos.
- Vazio: C = {}
- Finito: C = {1, 2, 3, 4}
- Infinito: C = {1, 2, 3, 4, ...}
---
## Operações

#### União
-> Se temos 2 conjuntos A e B, a união entre eles é escrita como A U B e representa todos os elementos de A e B combinados em um único conjunto.
- A = {14, 3}
- B = {10, 2}
- C = A U B = {2, 3, 10, 14}
---
#### Interseção
-> Se temos 2 conjuntos A e B, a interseção entre eles é escrita como A interseção B e representa todos os conjuntos que aparecem tanto em A quanto em B.
- A = {10, 3}
- B = {10, 2}
- C = A interseção B = {10}
---
## Sequência
-> Lista de objetos na mesma ordem
- (3, 42, 15) != (42, 3, 15)
-> Se houver qualquer repetição, também importa, então sequências tem que ser exatamente iguais em elementos e ordem dos mesmos.
-> Podem ser finitas ou infinitas.
-> São comumente chamadas de uplas, onde as sequências tem k=valor de elementos, ou seja, k-uplas.

---

**Conjuntos e sequências podem aparecer como elementos de outros conjuntos e sequências.**

A = {0, 1}
Conjuntos das partes de A = {vazio, {0}, {1}, {0, 1}}

---
**Produto Cartesiano de conjuntos**
- Sejam A e B dois conjuntos, A X B é o conjunto de todos os pares (ou duplas) onde o primeiro elemento de A e o segundo elemento de B.
	- A = {5, 3}
	- B = {a, b, c}
	- A X B = {(5, a), (5, b), (5, c), (3, a), (3, b), (3, c)}
---
## Função
-> Objeto que estabelece uma relação de entrada e saída.
-> A mesma entrada sempre produz a mesma saída.
-> Também chamada de mapeamento.
- Conjunto de possíveis entradas: Domínio
- Conjunto de possíveis entradas: Contradomínio
