
## O que faz um QA?

-> Profissional de testes que não se importa apenas com o código do produto, mas sim com todo o processo de entrega relacionado ao trabalho, ou seja, funciona como um gestor.

-> Previne defeitos antes que eles cheguem ao consumidor.

-> Melhora os processos de trabalho e a eficiência das operações, evita desvios.

---
## Padrão de Qualidade:

-> Existem dois padrões possíveis (internacional e brasileiro)
	- Internacional: CMMI que é o padrão de testes software que vai de 1 a 5, para garantir a qualidade de software.
	- Brasileiro: MPS.BR que funciona também como um padrão de testes de software que vai do G para o A, onde o G é o pior e o A é o maior.
