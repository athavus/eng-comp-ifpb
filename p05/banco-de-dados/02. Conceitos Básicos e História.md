## O Que São Bancos de Dados?

- São todas as formas de armazenar dados, independentemente da tecnologia. (Dados não são informação).

**Dados é o bruto, informação é o processado**

- Conjunto de dados organizados que se relacionam.

## História

- Década de 50:
	- Dados armazenados no papel

- Década de 60:
	- Computadores empresariais;
	- Dados armazenados em cartões perfurados e fitas magnéticas.

- CODASYL:
	- Conferência realizada para apresentar soluções para armazenar dados;
	- Criação da linguagem COBOL;
	- Bancos de Dados Não Relacionados.

- Década de 70:
	- Surgimento da Linguagem SQL;
	- Bancos de Dados Relacional.
