### Quem idealizou?

Foi fundamentada pelo modelo relacional definido por E. F. Codd, criado em 1970.
### Quem aplicou de fato?

D. D. Chamberlain e outros pesquisadores nos laboratórios de pesquisa da IBM na California, em 1974.

Tendo sua primeira versão chamada de SEQUEL (Structured English Query Language), sendo a linguagem de acesso a bancos de dados relacionais.

### O que ela tem?

Possui comandos de:
- Definição
- Consultas
- Atualização de dados

Sendo vista por duas divisões: Núcleo e Pacote.
- Núcleo é que o é implementado por todos os SGBDs;
- Pacotes são módulos opcionais que trazem funcionalidades novas, como bancos de dados temporais, com suporte a decisão, geográficos e multimídia.
