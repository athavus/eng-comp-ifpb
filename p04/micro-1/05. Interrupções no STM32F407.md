## O que são interrupções?

 -> São sinais (normalmente de hardware) que fazem o processador parar o que está fazendo, executar uma ISR (Interrupt Service Routine) e depois voltar pra tarefa anterior.

-> Muito mais eficientes que programar no modo polling, já que você não precisa ficar verificando constantemente se o periférico gerou algum evento.

## NVIC (Nested Vectored Interrupt Controller)

-> Controlador de interrupções da família Cortex-M4 (STM32F407).

-> Suporta até 256 fontes, mas no STM32F407 apenas 92 são implementadas.

-> Permite prioridades (0 = mais alta; 15 = mais baixa).

-> Possibilita interrupções aninhadas (uma de maior prioridade interrompe a ISR atual).

## Tipos de exceções

1. Exceções do sistema (Reset, NMI, HardFault, SysTick, etc.) – IDs de -15 a -1.
2. Interrupções de periféricos – IDs de 0 até 240 (dependendo do chip).

## CMSIS

-> Biblioteca padrão que fornece funções prontas para configurar interrupções.

-> Exemplos úteis:

```
NVIC_EnableIRQ(IRQn);               // habilita interrupção
NVIC_DisableIRQ(IRQn);              // desabilita interrupção
NVIC_SetPriority(IRQn, prioridade); // define prioridade
```

## Interrupções externas (EXTI)

-> Até 23 linhas de interrupção, sendo 16 ligadas a GPIOs (EXTI0–EXTI15).

-> Cada EXTIx pode ser associado a pinos diferentes (PAx, PBx, PCx...).

-> Precisam ser roteadas via SYSCFG->EXTICR.

-> O disparo pode ser configurado em borda de subida, descida ou ambas (RTSR/FTSR).

-> ISR obrigatória deve limpar o bit de pendência (PR).


Exemplo de configuração GPIO + EXTI:

```
// 1. Habilita clocks
RCC->AHB1ENR |= RCC_AHB1ENR_GPIOAEN;   // habilita GPIOA
RCC->APB2ENR |= RCC_APB2ENR_SYSCFGEN; // habilita SYSCFG

// 2. Configura PA0 como entrada
GPIOA->MODER &= ~GPIO_MODER_MODER0;

// 3. Roteia PA0 -> EXTI0
SYSCFG->EXTICR[0] &= ~SYSCFG_EXTICR1_EXTI0;
SYSCFG->EXTICR[0] |= SYSCFG_EXTICR1_EXTI0_PA;

// 4. Configura disparo na borda de subida
EXTI->RTSR |= EXTI_RTSR_TR0;

// 5. Habilita linha no IMR
EXTI->IMR |= EXTI_IMR_MR0;

// 6. Define prioridade e habilita no NVIC
NVIC_SetPriority(EXTI0_IRQn, 2);
NVIC_EnableIRQ(EXTI0_IRQn);
```

ISR correspondente:

```
void EXTI0_IRQHandler(void) {
    if (EXTI->PR & EXTI_PR_PR0) {
        EXTI->PR |= EXTI_PR_PR0; // limpa flag de pendência (pode ser usando a função EXTI_ClearPending da biblioteca Utility também, consulte.)
        // Código da interrupção aqui
    }
}
```

## Diferença interrupção x evento no EXTI

-> Interrupção → Executa uma ISR (processador realmente para e trata).

-> Evento → Pode disparar outro periférico (ex: ADC + DMA) sem intervenção do processador.
