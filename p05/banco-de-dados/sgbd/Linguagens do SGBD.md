# DDL (Data Definition Language)

- Especifica o schema para o banco de dados.
- CUD (Create, Update e Delete) das tabelas.

COMANDOS:
- CREATE
- ALTER
- DROP
# DML (Data Manipulation Language)

- Manipula o banco de dados.
	- Insere novos dados.
	- Altera dados.
	- Excluí dados.

COMANDOS:
- INSERT
- UPDATE
- DELETE
# DQL (Data Query Language)

- Responsável pela seleção de registros em uma ou mais tabelas (SELECT ou READ).

COMANDOS:
- SELECT
	- DISTINCT
	- IS NULL/NOT NULL
	- Funções Embutidas
	- GROUP BY
	- BETWEEN
	- LIKE
	- Aritméticos
	- ORDER BY

# DCL (Data Control Language)

- Controla a Autorização e direitos de acesso ao banco de dados.
- Mais relacionado com a segurança do banco de dados.

COMANDOS: 
- GRANT
- REVOKE

# DTL (Data Transaction Language)

- Gerencia as transações de um banco de dados.

COMANDOS:
- COMMIT
- ROLLBACK
- SAVEPOINT
