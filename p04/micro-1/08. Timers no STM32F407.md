# Timers no STM32F407

## 1. Introdução aos Timers

### Conceitos Fundamentais

- **Timer**: Contador que incrementa/decrementa automaticamente a cada pulso
- **Temporização**: Contagem de pulsos com frequência fixa para medir tempo
- **Base de clock**: Oscilador de quartzo (frequência precisa e estável)
- **Overflow**: Reinício automático quando valor máximo é ultrapassado

### Medição de Tempo

```
Tempo transcorrido = (B - A) × período_oscilação
```

- A = valor inicial do timer
- B = valor final do timer
- Se oscilador = 1MHz → período = 1µs

### Características por Resolução

- **8 bits**: 2⁸ = 256 pulsos máximo
- **16 bits**: 2¹⁶ = 65.536 pulsos máximo
- **32 bits**: 2³² = ~4 bilhões pulsos máximo

### Prescaler

- **Função**: Divide clock do sistema por fator configurável
- **Trade-off**:
    - Clock rápido → alta resolução, tempo máximo menor
    - Clock lento → baixa resolução, tempo máximo maior
- **STM32**: Prescaler 16 bits (divisão 1-65536)

## 2. Timer SysTick

### Características

- **Resolução**: 24 bits decrescente
- **Integração**: Parte do NVIC (exceção #15)
- **Clock**: AHB (168MHz) ou AHB/8
- **Aplicações**: RTOS, multitasking, delays, tarefas periódicas

### Funcionamento

1. Contador carregado com valor do registrador LOAD
2. Decrementa até zero
3. Ao atingir zero: recarrega automaticamente e gera interrupção
4. Processo se repete indefinidamente

### Fórmulas

```
Período de interrupção = (SysTick_LOAD + 1) × Clock_Period
```

### Registrador SysTick_CTRL

|Bit|Nome|Função|
|---|---|---|
|0|ENABLE|Habilita contagem|
|1|TICKINT|Habilita interrupções|
|2|CLKSOURCE|Fonte clock (AHB ou AHB/8)|
|16|COUNTFLAG|Flag transição 1→0|

### Exemplo de Configuração

```c
// SysTick configurado para 1ms @ 168MHz
SysTick->LOAD = 168000 - 1;     // 168MHz/1000 - 1
SysTick->VAL = 0;               // Limpa contador
SysTick->CTRL = 0x07;           // Enable + interrupt + AHB clock
```

## 3. Classificação dos Timers STM32F407

### Timers de Controle Avançado

**TIM1, TIM8**

- **Resolução**: 16 bits
- **Canais**: 4 captura/comparação
- **PWM**: 6 canais trifásicos complementares
- **Dead time**: Programável
- **Frequência**: Até 168MHz
- **Aplicações**: Controle de motores trifásicos

### Timers de Uso Geral

#### Grupo 1: TIM2, TIM3, TIM4, TIM5

- **TIM2, TIM5**: 32 bits, 4 canais
- **TIM3, TIM4**: 16 bits, 4 canais
- **Recursos completos**: Captura, comparação, PWM
- **Timer Link**: Sincronização entre timers
- **Encoders**: Suporte a quadratura

#### Grupo 2: TIM9-TIM14

- **Resolução**: 16 bits
- **TIM9, TIM12**: 2 canais
- **TIM10, TIM11, TIM13, TIM14**: 1 canal
- **Sincronização**: Com timers principais

### Timers Básicos

**TIM6, TIM7**

- **Resolução**: 16 bits
- **Canais**: 0 (apenas contagem)
- **Aplicação principal**: Trigger para DAC
- **Uso secundário**: Base de tempo genérica

### Timers Especiais

#### Independent Watchdog

- **Resolução**: 12 bits + prescaler 8 bits
- **Clock**: RC interno 32kHz independente
- **Função**: Reset automático em travamentos
- **Vantagem**: Opera em modos de baixo consumo

#### Window Watchdog

- **Resolução**: 7 bits
- **Clock**: Clock principal
- **Função**: Reset em janela de tempo específica
- **Recursos**: Interrupção, debug freeze

#### Aplicações Práticas dos Timers

- **Delays precisos**
- **Controle PWM** (motores, LEDs, servos)
- **Medição de tempo** entre eventos
- **Sincronização** de periféricos
- **Base de tempo** para RTOS
- **Trigger automático** para ADC/DAC
- **Contagem de eventos** externos
- **Geração de formas de onda**

## Timer TIM2 - Arquitetura

### Componentes principais

- **Contador CNT**: 32 bits crescente/decrescente
- **Prescaler (PSC)**: 16 bits, divide clock de entrada por fator 1-65536
- **Auto-reload Register (ARR)**: Valor máximo/inicial da contagem
- **Clock**: 84MHz do barramento APB1 (ou fontes externas)

### Modos de Contagem

#### Contagem Crescente

- Inicia em 0, vai até ARR, depois reinicia
- **Período**: `(1 + ARR) * (1/CK_CNT)`

#### Contagem Decrescente

- Inicia em ARR, decrementa até 0, reinicia em ARR
- **Período**: `(1 + ARR) * (1/CK_CNT)`

#### Contagem Center-Aligned

- 0 → ARR → 0 (triangular)
- **Período**: `2 * ARR * (1/CK_CNT)`

### Eventos de Atualização

- **Overflow**: Mudança do valor máximo para 0
- **Underflow**: Recarregamento com valor ARR

## Modos de Operação

### 1. Output Compare (Comparação de Saída)

- Compara CNT com valor constante (CCR)
- Gera sinal de saída ou interrupção quando iguais
- Usado para controle de periodicidade

### 2. Input Capture (Captura de Entrada)

- Captura valor de CNT automaticamente em evento externo
- Armazena em registrador CCR
- Usado para medir intervalos de tempo

### 3. Contagem Livre

- Timer conta livremente como base de tempo
- Configuração básica para funções de delay

```c
// Configuração básica TIM2
void TIM2_Setup() {
    RCC->APB1ENR |= 1;          // Liga clock Timer2
    TIM2->CR1 &= ~(1 << 4);     // Contagem crescente
    TIM2->PSC = 83;             // Prescaler para 1µs
    TIM2->EGR = 1;              // Update event
    TIM2->CR1 |= 1;             // Habilita timer
}

// Função de delay
void Delay_us(uint32_t delay) {
    TIM2->CNT = 0;
    while(TIM2->CNT < delay);
}
```

## PWM (Pulse Width Modulation)

### Conceitos Fundamentais

- **Período PWM**: `tPWM = t1 + t2`
- **Frequência PWM**: `fPWM = 1/tPWM`
- **Duty Cycle**: `(t1/tPWM) * 100%`

### Vantagens do Controle PWM

- Eficiência até 98%
- Baixa dissipação de calor
- Controle preciso de potência
- Não necessita grandes dissipadores

### Aplicações

- Controle de velocidade de motores
- Controle de luminosidade (LEDs, lâmpadas)
- Servo motores
- Controle de temperatura
- Conversores DAC
- Inversores fotovoltaicos

## Módulo Compare Output - Geração PWM

### Modos de Comparação (OCM[2:0])

|Modo|Código|Comportamento|
|---|---|---|
|Temporização|000|Sem efeito|
|Ativo|001|HIGH se CNT=CCR|
|Inativo|010|LOW se CNT=CCR|
|Alternância|011|Alterna se CNT=CCR|
|Inativo forçado|100|Sempre LOW|
|Ativo forçado|101|Sempre HIGH|
|**PWM 1**|**110**|**Crescente: HIGH se CNT<CCR**|
|**PWM 2**|**111**|**Crescente: HIGH se CNT≥CCR**|

### Características PWM

- **Período**: `tPWM = (1 + ARR) * ttimer`
- **Duty Cycle**: `CCR/(1 + ARR)`
- Todos os canais compartilham mesmo período
- Cada canal tem seu próprio CCR (duty cycle independente)

### Exemplo: Configuração TIM5 para PWM

```c
// Configuração GPIO e Timer
RCC->AHB1ENR |= 1;                    // Clock GPIOA
GPIOA->MODER |= (0b10 << 4);          // PA2 função alternativa
GPIOA->AFR[0] |= (0b0010 << 8);       // AF2 (TIM5)

RCC->APB1ENR |= (1 << 3);             // Clock Timer5
TIM5->CR1 &= ~(1 << 4);               // Contador crescente
TIM5->ARR = 99;                       // Resolução 1% (0-100)
TIM5->PSC = 419;                      // Frequência 2kHz
TIM5->CCMR2 |= (0b11 << 5);           // PWM modo 1
TIM5->CCMR2 |= (1 << 3);              // Pré-carregamento CCR3
TIM5->CCER |= (1 << 8);               // Habilita saída
TIM5->EGR = 1;                        // Update event
TIM5->CR1 |= 1;                       // Habilita timer

// Atualização duty cycle (0-100)
TIM5->CCR3 = duty_cycle;
```

## Saídas de Disparo (TRGO)

### Funcionalidade

- Sincronização entre timers
- Disparo automático de conversões ADC/DAC
- Encadeamento de temporizadores

### Fontes de TRGO

- **Reset**: Bit UG do registrador EGR
- **Enable**: Sinal de habilitação do timer
- **Update**: Evento de atualização
- **Compare**: Pulso quando CC1IF setado
- **OCxRef**: Sinais de referência dos canais

### Exemplo: Timer3 → ADC1

```c
// Timer3 como master (TRGO a cada 200ms)
RCC->APB1ENR |= RCC_APB1ENR_TIM3EN;
TIM3->CR1 &= ~TIM_CR1_DIR;            // Crescente
TIM3->PSC = 419;                      // 5µs por tick
TIM3->ARR = 40000;                    // Overflow a cada 200ms
TIM3->CR2 = 0b010 << 4;               // TRGO no overflow
TIM3->CR1 |= TIM_CR1_URS;             // Overflow → TRGO
TIM3->CR1 |= TIM_CR1_CEN;             // Habilita

// ADC1 disparado por TIM3_TRGO
ADC1->CR2 |= 0b1000 << 24;            // TIM3_TRGO como trigger
ADC1->CR2 |= ADC_CR2_EXTEN_0;         // Rising edge trigger
ADC1->CR1 |= 1 << 5;                  // Interrupção EOC
```

## Resumo de Registradores Importantes

- **CNT**: Contador atual
- **PSC**: Prescaler (divisor de clock)
- **ARR**: Auto-reload (valor máximo/período)
- **CCR**: Compare/Capture (duty cycle no PWM)
- **CR1**: Controle principal
- **CR2**: Controle secundário (TRGO)
- **CCMR**: Modo capture/compare
- **CCER**: Enable capture/compare
